# AMJT - Area do Associado (Mobile)

Aplicativo Expo/React Native para a area do associado, consumindo o backend do projeto em `server`.

## Configuracao da API

Por padrao o app usa `https://api.amjt2.com.br`. Para trocar, defina a variavel abaixo ao iniciar o Expo:

```bash
EXPO_PUBLIC_API_URL=http://127.0.0.1:3001 npx expo start
```

## Como rodar

```bash
npm install
npx expo start
```
